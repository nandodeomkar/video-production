# Pop-Clip Workflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a third video-stylization pipeline, `pop-clip`, that turns an image or a short online-video section into pop-art / comic-book style — flat saturated colour, halftone dots in shadows, bold black inked outlines.

**Architecture:** A new render engine `Libraries\PopArt\popart_render.py` plus a `bin\pop-clip\` folder of stage scripts, structurally identical to the existing `char-clip` pipeline. The engine runs five ordered passes (PUNCH → SMOOTH → QUANTIZE → HALFTONE → OUTLINE) on one image to one explicit output path, so the Stage 3 script can render frames in parallel. Stages 1–2 (download, extract) are reused from `bin\tiled-clip\`; stages 3–4 are pop-clip's own.

**Tech Stack:** Python 3.13 with `cv2` (OpenCV) and `numpy` — both already in `Libraries\Tiler\.venv`. Colour quantization uses `cv2.kmeans` (OpenCV built-in — no `sklearn` needed). Tests use Python's stdlib `unittest` (no `pytest` install required). Pipeline orchestration is Windows `.cmd` batch + a PowerShell 5.1 parallel renderer.

**Reference spec:** `docs\superpowers\specs\2026-05-17-pop-clip-design.md`

```python
def punch(img, saturation):
    """Boost saturation and contrast so colours read loud.

    Saturation is scaled on the HSV S channel; contrast is a linear stretch
    around mid-grey on the BGR pixels. Both are clipped back into 0-255.
    """
    hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV).astype('float32')
    hsv[:, :, 1] = np.clip(hsv[:, :, 1] * saturation, 0, 255)
    boosted = cv2.cvtColor(hsv.astype('uint8'), cv2.COLOR_HSV2BGR)

    stretched = (boosted.astype('float32') - 128.0) * CONTRAST_FACTOR + 128.0
    return np.clip(stretched, 0, 255).astype('uint8')
```

```python
def quantize(img, colors):
    """Reduce the image to `colors` dominant colours via k-means clustering.

    Every pixel is treated as a 3-D point (B, G, R). cv2.kmeans finds the
    `colors` cluster centres; each pixel is then snapped to its centre. The
    result is a true limited palette — flat comic colour.
    """
    samples = img.reshape(-1, 3).astype('float32')
    criteria = (cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER,
                KMEANS_ITERATIONS, KMEANS_EPSILON)
    _, labels, centers = cv2.kmeans(
        samples, colors, None, criteria, KMEANS_ATTEMPTS,
        cv2.KMEANS_RANDOM_CENTERS)
    palette = centers.astype('uint8')
    quantized = palette[labels.flatten()]
    return quantized.reshape(img.shape)
```

```python
def halftone(img, shadow_cutoff, cell):
    """Overlay black comic dots wherever the image is in shadow.

    The image is divided into `cell`-sized squares. For each cell, the mean
    brightness is measured; cells darker than `shadow_cutoff` get a black dot
    drawn at their centre. Brighter cells are left as flat colour. The result
    is the classic newsprint dot texture, confined to the shadows.
    """
    out = img.copy()
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    h, w = gray.shape
    radius = max(1, int(cell * HALFTONE_DOT_RATIO))
    for y in range(0, h - cell + 1, cell):
        for x in range(0, w - cell + 1, cell):
            block = gray[y:y + cell, x:x + cell]
            if block.mean() < shadow_cutoff:
                center = (x + cell // 2, y + cell // 2)
                cv2.circle(out, center, radius, (0, 0, 0), -1, cv2.LINE_AA)
    return out
```

# OUTLINE edge detection (Difference-of-Gaussians).
#   DOG_BLUR_NARROW / DOG_BLUR_WIDE : the two Gaussian blur kernel sizes;
#       their difference isolates edges. Both must be odd.
#   EDGE_BASE_THRESHOLD : DoG response above this becomes an inked pixel.
#       Divided by edge_strength, so a larger --edge-strength inks more.
#   OUTLINE_DILATE : kernel size for thickening the detected lines so they
#       read as bold comic ink rather than thin hairlines.
DOG_BLUR_NARROW = 3
DOG_BLUR_WIDE = 9
EDGE_BASE_THRESHOLD = 12.0
OUTLINE_DILATE = 2
```

Then add the `outline` function (above `render`):

```python
def outline(img, edge_strength):
    """Ink bold black outlines on the image's major boundaries.

    Edges are found by Difference-of-Gaussians: two Gaussian blurs at
    different radii are subtracted, leaving a strong response only where the
    image changes sharply. The response is thresholded into an edge mask, the
    mask is dilated so lines read as bold ink, and those pixels are painted
    black on top of the input.
    """
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY).astype('float32')
    narrow = cv2.GaussianBlur(gray, (DOG_BLUR_NARROW, DOG_BLUR_NARROW), 0)
    wide = cv2.GaussianBlur(gray, (DOG_BLUR_WIDE, DOG_BLUR_WIDE), 0)
    dog = np.abs(narrow - wide)

    threshold = EDGE_BASE_THRESHOLD / max(edge_strength, 0.01)
    mask = (dog > threshold).astype('uint8')
    if OUTLINE_DILATE > 0:
        kernel = np.ones((OUTLINE_DILATE, OUTLINE_DILATE), dtype='uint8')
        mask = cv2.dilate(mask, kernel)

    out = img.copy()
    out[mask > 0] = (0, 0, 0)
    return out
```

Add the `auto_normalize` helper (above `render`):

```python
def auto_normalize(img):
    """Stretch a frame's brightness to the full range, preserving colour.

    Works on the HSV value channel only — hue and saturation untouched — so a
    dark, colour-cast frame is lifted into a visible range without
    neutralizing its colours. Low/high percentiles (not absolute min/max) map
    to 0/255 so outlier pixels do not pin the range.
    """
    hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
    v = hsv[:, :, 2]
    lo, hi = np.percentile(v, (NORM_LOW_PCT, NORM_HIGH_PCT))
    if hi <= lo:
        return img  # flat frame — nothing to stretch
    stretched = (v.astype('float32') - lo) * (255.0 / (hi - lo))
    hsv[:, :, 2] = np.clip(stretched, 0, 255).astype('uint8')
    return cv2.cvtColor(hsv, cv2.COLOR_HSV2BGR)
```

Now replace the stub `render` function entirely with:

```python
def render(img, colors, shadow_cutoff, saturation, edge_strength, cell,
           normalize):
    """Stylize a BGR image into pop-art and return the rendered canvas.

    Runs the five passes in order. The canvas is first cropped to a whole
    number of `cell`-sized squares so the halftone grid divides evenly — this
    keeps the output a stable size, suitable for a video-frame stage.

    When `normalize` is True the frame's brightness is stretched to the full
    range first — helps dark footage render with vivid colour.
    """
    if normalize:
        img = auto_normalize(img)

    # Crop to a whole number of halftone cells so the grid divides evenly.
    h, w = img.shape[:2]
    out_h = max(cell, (h // cell) * cell)
    out_w = max(cell, (w // cell) * cell)
    img = img[:out_h, :out_w]

    img = punch(img, saturation)
    img = smooth(img)
    img = quantize(img, colors)
    img = halftone(img, shadow_cutoff, cell)
    img = outline(img, edge_strength)
    return img
```

Create `bin\pop-clip\render-frames.ps1`:

```powershell
# =============================================================================
#  Parallel frame renderer for the pop-clip pipeline (Stage 3 helper).
#
#  Renders every PNG in -FrameDir through popart_render.py into -OutDir,
#  running up to -Concurrency frames at once via throttled background jobs.
#
#  Windows PowerShell 5.1 compatible (no ForEach-Object -Parallel).
#
#  Params:
#    -PythonExe     full path to a venv python.exe with cv2 + numpy
#    -PopArtDir     Libraries\PopArt  (contains popart_render.py)
#    -FrameDir      folder of input frames (f_*.png)
#    -OutDir        folder to write stylized frames into
#    -Colors        palette size (k-means clusters)
#    -ShadowCutoff  brightness 0-255 below which halftone dots appear
#    -Saturation    saturation boost factor
#    -Cell          halftone dot-grid cell size in pixels
#    -Normalize     switch: auto-stretch frame brightness before stylizing
#    -Concurrency   max frames in flight at once   (default 8)
# =============================================================================
param(
    [Parameter(Mandatory = $true)][string]$PythonExe,
    [Parameter(Mandatory = $true)][string]$PopArtDir,
    [Parameter(Mandatory = $true)][string]$FrameDir,
    [Parameter(Mandatory = $true)][string]$OutDir,
    [int]$Colors = 8,
    [int]$ShadowCutoff = 100,
    [double]$Saturation = 1.6,
    [int]$Cell = 6,
    [switch]$Normalize,
    [int]$Concurrency = 8
)

$ErrorActionPreference = 'Stop'

if (-not (Test-Path $OutDir)) { New-Item -ItemType Directory -Path $OutDir | Out-Null }

$frames = Get-ChildItem -Path $FrameDir -Filter 'f_*.png' | Sort-Object Name
if ($frames.Count -eq 0) {
    Write-Error "No frames found in $FrameDir"
    exit 1
}

Write-Host "Pop-arting $($frames.Count) frames, $Concurrency at a time (colors $Colors, cell $Cell)..."

# --normalize is a presence-only flag. Each job builds its full argument list
# by concatenation below — an empty $normFlag then contributes zero elements.
$normFlag = if ($Normalize) { @('--normalize') } else { @() }

# One job = stylize one frame. popart_render.py must run with cwd = PopArtDir
# so its 'import cv2' resolves against the venv. Success is judged by exit
# code AND the output file existing.
$worker = {
    param($py, $dir, $script, $inPng, $outPng, $colors, $shadow, $sat, $cell, $normFlag)
    $ErrorActionPreference = 'Continue'
    Set-Location $dir
    $pyArgs = @($script, $inPng, $outPng,
                '--colors', $colors, '--shadow-cutoff', $shadow,
                '--saturation', $sat, '--cell', $cell) + $normFlag
    & $py @pyArgs 2>&1 | Out-Null
    if ($LASTEXITCODE -ne 0 -or -not (Test-Path $outPng)) {
        throw "popart_render failed for $inPng (exit $LASTEXITCODE)"
    }
}

$scriptPath = Join-Path $PopArtDir 'popart_render.py'
$jobs = @()
$done = 0
$failed = 0
$total = $frames.Count

foreach ($frame in $frames) {
    # Throttle: wait until a job slot frees up.
    while (@($jobs | Where-Object { $_.State -eq 'Running' }).Count -ge $Concurrency) {
        Wait-Job -Job $jobs -Any | Out-Null
        foreach ($j in @($jobs | Where-Object { $_.State -ne 'Running' })) {
            if ($j.State -eq 'Failed') { $failed++; Write-Warning ($j.ChildJobs[0].JobStateInfo.Reason.Message) }
            try { Receive-Job -Job $j -ErrorAction SilentlyContinue | Out-Null } catch { $failed++; Write-Warning $_.Exception.Message }
            Remove-Job -Job $j
            $done++
        }
        $jobs = @($jobs | Where-Object { $_.State -eq 'Running' })
        Write-Host ("  progress: {0}/{1}" -f $done, $total)
    }

    $outPng = Join-Path $OutDir $frame.Name
    $jobs += Start-Job -ScriptBlock $worker -ArgumentList `
        $PythonExe, $PopArtDir, $scriptPath, $frame.FullName, $outPng, $Colors, $ShadowCutoff, $Saturation, $Cell, $normFlag
}

# Drain remaining jobs.
while ($jobs.Count -gt 0) {
    Wait-Job -Job $jobs -Any | Out-Null
    foreach ($j in @($jobs | Where-Object { $_.State -ne 'Running' })) {
        if ($j.State -eq 'Failed') { $failed++; Write-Warning ($j.ChildJobs[0].JobStateInfo.Reason.Message) }
        try { Receive-Job -Job $j -ErrorAction SilentlyContinue | Out-Null } catch { $failed++; Write-Warning $_.Exception.Message }
        Remove-Job -Job $j
        $done++
    }
    $jobs = @($jobs | Where-Object { $_.State -eq 'Running' })
    Write-Host ("  progress: {0}/{1}" -f $done, $total)
}

if ($failed -gt 0) {
    Write-Error "$failed of $total frames failed to pop-art."
    exit 1
}

Write-Host "All $total frames pop-arted into $OutDir"
exit 0
```

```markdown
# Pop-Clip Workflow

Stylize an image — or a short section of any online video — into **pop-art /
comic-book style**: flat saturated colour, halftone dots in the shadows, and
bold black inked outlines.

## What the look is made of

Every frame runs through five passes:

| Pass | Effect |
|------|--------|
| Punch    | Saturation + contrast boosted so colour reads loud |
| Smooth   | Edge-preserving blur flattens skin/fabric micro-texture |
| Quantize | Colours reduced to a small palette via k-means — flat comic colour |
| Halftone | Shadow regions get a grid of black dots — the newsprint texture |
| Outline  | Major edges inked bold black, drawn on top |

The original hues are kept (then boosted), so scenes and faces stay
recognizable — it reads as a comic adaptation of the real footage, not a
random recolour.

## Two ways to use it

### A single image

\```
bin\pop-clip\stylize-image.cmd  INPUT OUTPUT [COLORS] [SHADOW_CUTOFF] [SATURATION] [CELL] [NORMALIZE]
\```

Example:

\```
bin\pop-clip\stylize-image.cmd photo.jpg photo_pop.png 8 100 1.6 6 off
\```

`INPUT` / `OUTPUT` may be relative or absolute. The output's parent folder is
created if missing.

### A video section

\```
bin\pop-clip\run-all.cmd  URL START END CLIPNAME [COLORS] [SHADOW_CUTOFF] [SATURATION] [CELL] [NORMALIZE]
\```

Example — a 4-second section:

\```
bin\pop-clip\run-all.cmd "https://youtu.be/XXXX" 00:01:12 00:01:16 newsclip1
\```

Result: `Output\newsclip1_popart.mp4`

`START` / `END` accept `HH:MM:SS` or plain seconds. `CLIPNAME` becomes the
work-folder name and the output filename prefix.

> **Paste the bare `youtu.be/<id>` URL.** A `?si=...` share suffix (added by
> YouTube's Copy-link button) breaks `cmd` argument parsing — strip it.

## What the video pipeline does

\```
YouTube URL + start/end timestamp
        |
   [1] download    -> Work/<clip>/source.mp4        trimmed, up to 1080p
   [2] extract     -> Work/<clip>/frames/f_*.png     30fps PNG sequence
                      Work/<clip>/audio.m4a          original audio (copied)
   [3] popart      -> Work/<clip>/popart/f_*.png     each frame -> pop-art
   [4] stitch      -> Output/<clip>_popart.mp4       final video + audio
\```

Stages 1 and 2 are **shared with the tiled-clip and char-clip pipelines** —
`run-all.cmd` calls the tiled-clip implementations directly. Stages 3 and 4
are pop-clip's own.

## Running stages individually

| Stage | Command | Produces |
|-------|---------|----------|
| 1 | `..\tiled-clip\1-download.cmd URL START END CLIPNAME` | `Work\<clip>\source.mp4` |
| 2 | `..\tiled-clip\2-extract-frames.cmd CLIPNAME` | `Work\<clip>\frames\`, `audio.m4a` |
| 3 | `3-popart-frames.cmd CLIPNAME [COLORS] [SHADOW_CUTOFF] [SATURATION] [CELL] [NORMALIZE]` | `Work\<clip>\popart\` |
| 4 | `4-stitch.cmd CLIPNAME` | `Output\<clip>_popart.mp4` |

## Tuning

All knobs are command-line arguments — no file edits needed.

- **`COLORS`** — palette size, the number of k-means colour clusters
  (default `8`). Fewer = bolder, blockier, more abstract; more = subtler.
- **`SHADOW_CUTOFF`** — brightness 0-255 below which halftone dots appear
  (default `100`). Lower = dots only in deep shadow; higher = dots spread into
  the midtones for a heavier comic texture.
- **`SATURATION`** — saturation boost factor (default `1.6`). Higher = louder,
  more pop-art colour.
- **`CELL`** — halftone dot-grid cell size in pixels (default `6`). Bigger =
  larger, sparser dots.
- **`NORMALIZE`** — `on` | `off` (default `off`). Auto-stretches each frame's
  brightness before stylizing. Turn `on` for dark footage.

Deeper look-tuning lives in constants at the top of
`Libraries\PopArt\popart_render.py`:

- `CONTRAST_FACTOR` — contrast stretch strength in the Punch pass.
- `BILATERAL_DIAMETER` / `BILATERAL_SIGMA` — Smooth pass blur strength.
- `KMEANS_ITERATIONS` / `KMEANS_EPSILON` / `KMEANS_ATTEMPTS` — quantization
  quality vs. speed.
- `HALFTONE_DOT_RATIO` — dot radius as a fraction of the cell.
- `DOG_BLUR_NARROW` / `DOG_BLUR_WIDE` / `EDGE_BASE_THRESHOLD` /
  `OUTLINE_DILATE` — outline edge detection and line thickness.

## Render cost

Pop-arting is pure cv2/numpy. The k-means quantization is the heaviest pass.
Stage 3 renders frames in parallel (`CONCURRENCY=8`, editable at the top of
`3-popart-frames.cmd`). A 4-second clip (~120 frames at 30fps) renders in
roughly 1-3 minutes on a multi-core machine.

| Path | Role |
|------|------|
| `Libraries\PopArt\popart_render.py` | the engine: stylizes one image to pop-art |
| `Libraries\PopArt\test_popart_render.py` | unit tests for the engine's passes |

| `bin\pop-clip\4-stitch.cmd` | Stage 4: stitch pop-art frames + audio |

| `bin\pop-clip\render-frames.ps1` | parallel frame renderer (Stage 3 helper) |
| `bin\tiled-clip\1-download.cmd` / `2-extract-frames.cmd` | shared stages 1-2 |
